# Movie discovery

The homepage has a draggable panorama with arrow controls, keyboard support, reflected posters and a details panel. Its now-showing collection filters by language. Dedicated movie discovery filters title, language, genre, format and rating and sorts by recommendation order, rating, title or duration. Language selection is represented in query parameters. Coming soon is a separate catalog category, and upcoming films can be saved to a device watchlist.

Movie pages contain configurable artwork, synopsis, genre, runtime, languages, cast, filmmaker, sample release date, formats and trailer. Only authorised direct video sources are played. Unconfigured trailers use an explicit unavailable state with a link to the licensed sample film.

The shared global search covers films, language/genre keywords, city-local cinemas/localities and cities. Suggestions support up/down/Enter, clearing and a keyboard shortcut. Search and listing empty states are deliberate.

Showtimes are grouped by venue for the selected film and city. Date, format, primary screening language, time of day and starting-price filters are functional. Films support several catalog languages; generated default screenings use the first configured language. This is a demo scheduling policy, not live localisation inventory.
