# Cinema discovery

The initial data defines 23 illustrative venues across ten cities. Each has a stable ID, local address, sample distance, facilities, supported formats, films, ticket-price offset and one or more assigned auditorium blueprints.

The cinema list filters search/locality, format, amenities, distance and movie. Sorting supports popular seed order, nearest sample distance, alphabetic name, price and movie count. Distance is configured demonstration data, not a live location calculation.

Every venue has a detail URL with its interior image, address, facilities, assigned screen count and all locally configured film screenings. Dates and showtime filters use the same component as movie pages. Selecting a screening enters the unified booking state without asking again for movie or venue.

A venue and an auditorium are separate entities. Indexing a venue's assigned blueprint IDs across its configured screening times determines the physical screen. Distinct rooms differ in dimensions, row lengths, capacity, aisles, slopes, balcony and recliner policy. All architecture is illustrative.
