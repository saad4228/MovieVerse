# 3D rendering architecture

`SeatScene.tsx` is dynamically imported. React Three Fiber owns the Canvas. Shared rounded seat components render as instanced meshes, with per-instance matrices and colours for identity, category, availability and selection. Rooms generate stepped floors, panelled walls, stage, screen, aisle lighting, signs and optional balcony geometry. Texture signs use native mesh planes. This avoids separate DOM/React roots per row.

The movie screen is a physical plane. The licensed Sintel clip is a bundled MP4 with a Three.js VideoTexture, muted autoplay, pause/resume, audio controls, media status, looping, texture disposal and element cleanup. Other catalog films use their own official YouTube players, perspective projected onto the screen using `ProjectedMovieScreen.tsx` and `lib/screen-projection.ts`. The camera world matrix is updated before computing all four screen corners, and the player is hidden when the screen is behind the camera. This keeps the official cross-origin player intact instead of trying to extract a YouTube video stream into WebGL. All films have individual media fields; changing the screening loads the booked film. An unavailable uploader offers an official external watch link.

The custom-model adapter uses GLTF loading and maps named clickable meshes to the same inventory IDs. Model coordinates, scale and mapping must match the configured blueprint. Local preview accepts .glb files; deployment requires an authorised HTTPS asset URL. No custom real-world models were provided, so that path is supported but not verified with a production model.

`AuditoriumDetails.tsx` adds procedural velvet folds, screen trim, a ceiling with light strips, acoustic/wood panels and a railing at the actual balcony floor height. Seat headrests and cup holders share instanced geometry; selected seats have labels and floor markers. A shared screen-frame calculation fits the room height and supplies the camera target. Media fits inside that frame while preserving its aspect ratio.

The renderer uses 2K Poly Haven colour/normal/roughness maps for fabric, carpet and wood, shared cached maps, anisotropic filtering, fabric sheen, ACES filmic tone mapping, antialiasing and HD device-pixel ratio up to 2.25. Static shadow maps are refreshed for room/lighting changes and reused during camera motion. Text signs use 1024-pixel canvases. Canvas and texture errors switch to the accessible 2D inventory. Mobile can select the 2D map at any time. SD reduces pixel ratio and disables shadows. The 3D bundle loads only for booking or Studio preview. Higher quality increases GPU cost; no fixed frame rate is promised across hardware.
