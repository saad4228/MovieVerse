# Platform expansion audit

Audit date: 2026-11-01. Existing app retained; no replacement scaffold.

- **Working:** transactional D1 screening inventory, holds, pricing, snacks, checkout, tickets and account isolation; city invalidation; physical VideoTexture with MP4/HLS, custom controls and fallback; bounded 3D camera and instanced seats. Existing regression suite: 25 unit and 16 browser tests.
- **Carousel defects:** release clamps movement to two positions, wide-screen drag uses 190px while rendering uses 212px, stale fling velocity survives release, metadata updates to a target while the visible centre still differs. No automatic rotation exists despite requested interaction rules. Replace the clamp with nearest-position snapping, shared spacing, stable refs and one cancellable animation owner; add explicit opt-in autoplay with interaction pauses.
- **Movie content gaps:** nine seed records, short demonstration descriptions, cast stored as strings with the last string incorrectly treated as filmmaker. Release status is static. No person photographs, verified credit roles, regional release provenance or alternative hero selection.
- **Image issues:** original posters already downloaded; backdrops have no explicit dimension-aware responsive resolver or composition metadata. Research the five priority films, preserve originals and alternatives, and use actual dimensions without enlargement.
- **Cinema gaps:** ten-city directory is arrays of names with index-based IDs and no branch/status metadata. It only appears under movie showtimes; the main cinema page shows generated demo venues. Introduce a separate stable-ID sourced directory and discoverable detail pages, preserving uncertain/closed candidates without fabricating screenings.
- **Showtime gaps:** generated schedules use only the first language, uniform price and decorative availability colours unrelated to inventory. Preserve existing screening IDs, add explicit schedule records/validation, and fetch availability summaries from the same inventory used during booking.
- **Trailer diagnosis:** commercial films have external official links, not direct media URLs. Their intentional artwork fallback is not a decoder failure. Preserve that distinction; test movie-specific source propagation, failed-source recovery and uninterrupted physical playback. Never substitute sample footage for a commercial title.
- **Integration boundaries:** TMDB credentials and licensed live cinema feeds are not configured. Bundled provenance-backed metadata and directory records must work without them. Provider interfaces and optional server-side adapters must keep metadata, imagery, directory, schedules, inventory and bookings separate.

Implementation: focused carousel repair; cached metadata/asset resolution; film story/cast/crew sections; regional date-based discovery; sourced multi-city directory; richer demo schedules and inventory-backed availability; targeted regression and visual review; updated source/coverage/testing reports.
